## B. For Sale page, sort and filters

### B1. Price sort/filter hidden (06:00–06:47)

### B2. Filters currently: bedroom, bathroom, garage, land, plus clickable
features (06:15–06:39)
- "Pretty good" but "needs to be a little bit rejigged".
- CASPIAN was not added yet ("I didn't put Caspi..."). "City View" is an
  example feature. Verify every residence has its filter values set.

### B3. Land size sort is wrong / mislabelled (06:51–08:30)
- What is labelled "Land size" is actually sorting/showing the BUILD size.
- The direction is not obvious to a buyer (largest to smallest?). Bedrooms show
  ascending/descending; land size should show the same.
- The bracket options (up to 600, 600–800, 800+) are land-size brackets, but
  everything Sabdia has now is 600+ so the bracketing may be pointless.
- Speaker 1: "if we are using it, it has to be correct." Buyers probably care
  about both house size and block size, "probably all the land".
- Suggestion (Speaker 3): differentiate the two with icons: a land/block icon
  for land size and a house icon for build size.

### B4. "How it works" block at the bottom of the residence page (09:08–09:39)
- Good to have, but likely not the right spot.
- Risk: it reads as the buying/contract process ("they might just go, shit,
  okay, he's gonna write the contract").

### B5. Private inspection kept, Guided Match removed (09:39–10:00)
